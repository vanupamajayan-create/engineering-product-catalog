HST4 Mechanical Installation Specification Matrix

This technical document contains verified engineering metrics for specifying and installing the HST4 wedge anchor system in structural concrete applications.

Torque & Dimension Thresholds

To ensure proper expansion sleeve deployment without inducing localized concrete cracking, installers must apply the following metrics using calibrated equipment:

  • M10 Anchor Size: Requires an installation torque (T_inst) of exactly 45 Nm. Standard embedment depth is 60mm.
  • M12 Anchor Size: Requires an installation torque (T_inst) of exactly 60 Nm. Standard embedment depth is 70mm.
  • M16 Anchor Size: Requires an installation torque (T_inst) of exactly 110 Nm. Standard embedment depth is 95mm.

Critical Material Limitations

Warning: Over-torqueing the assembly using unregulated impact tooling strips the expansion ring's grip profile against the concrete internal bore hole. Always complete the final tightening sequence manually to guarantee ultimate design tension values.
